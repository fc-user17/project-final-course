4. Administración y Finanzas

Este módulo controlaría la parte económica de la empresa.

* Registro de ingresos.
* Registro de gastos.
* Presupuestos.
* Costos de mantenimiento.
* Costos de materiales.
* Costos de mano de obra.
* Pagos.
* Cuentas por cobrar.
* Cuentas por pagar.
* Facturación.
* Control de presupuestos aprobados.
* Reportes financieros.
* Rentabilidad por servicio.

Una función interesante sería:

> *Costo real del mantenimiento = materiales + mano de obra + otros gastos*

Así la empresa puede saber cuánto le cuesta realmente realizar cada trabajo
